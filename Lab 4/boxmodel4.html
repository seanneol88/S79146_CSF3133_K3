Four layers, outside in

margin — 24px, outside the border, always transparent
border — 8px, the visible edge
padding — 24px, inside the border, same colour as the content
content — the text or image itself

The properties

Property Sits Takes a colour? Example
width / height Innermost — the content No width: 200px;
padding Between the content and the border No — takes the background colour padding: 20px;
border Around the padding Yes border: 5px solid #1f4e79;
margin Outside the border No — always transparent margin: 24px auto;

One property, four sides

margin: 10px 20px 30px 40px; is read clockwise from the top, so it means exactly the same as the four long-hand lines below it. With two values, margin: 10px 20px;, the first is top/bottom and the second is left/right. With one value all four sides match.

Why the two boxes below are different sizes

Both boxes are told width: 200px and both have 20px padding and a 5px border. The left one is the CSS default, content-box: the 200px covers the content only, so the box on the screen is 200 + 20 + 20 + 5 + 5 = 250px wide. The right one sets box-sizing: border-box, so the 200px covers everything and the content is squeezed to 150px.

content-box
screen width 250px
border-box
screen width 200px

That is why style4.css starts with * { box-sizing: border-box; } — one line that makes every width on the site mean what it says.

Centring a column

max-width: 960px; stops the column growing past 960px, and margin: 0 auto; shares the leftover space equally on the left and right. Together they centre the content without any float or flexbox: 

main {
    max-width: 960px;
    margin: 0 auto;
    padding: 24px 20px 48px;
}

That is the exact rule used by this page, and by every other page in Lab 4.
