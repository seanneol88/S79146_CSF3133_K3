Type (element) selector

.d-type em { background-color: #ffe9b8; }

Selects every emphasised word inside this panel. No class, no id — just the tag name, so all of them are touched.

Class selector

.d-highlight { background-color: #1f4e79; }

A class starts with a dot and may be reused: first badge, second badge, third badge.

Id selector

#d-special { border: 3px solid #c0392b; }

An id starts with a hash and may appear once per page. This whole panel is the single element carrying id="d-special", which is why it has the red frame.

Descendant vs child

.d-nav-demo a { color: #c0392b; }

Links anywhere inside this paragraph are red: one, two. But a link placed outside it stays normal, like this one.

.d-child-demo > li { color: #2e8b57; }
  • Green, because this is a direct child.
  • Green too.
    • Not green — a grandchild, and > only reaches one level down.

Grouping selectors

.d-group h4, .d-group p, .d-group li { font-family: Georgia; }

This heading is now serif

So is this paragraph, and the list item below.

  • One rule, three selectors, one set of declarations.

Pseudo-classes

li:nth-child(odd) { background-color: #eef4fa; }
  • Item 1 — odd, pale blue
  • Item 2 — even, gold
  • Item 3 — odd, pale blue
  • Item 4 — even, gold
li:first-child / li:last-child
  • First child: bold green
  • Middle child: untouched
  • Last child: italic red
a:hover { ... } input:focus { ... }

Pseudo-elements

p::first-letter { float: left; font-size: 3rem; }

The first letter of this paragraph has been lifted out of the line and enlarged, exactly like a printed magazine. The trick is a single pseudo-element — the markup itself carries no extra span at all.

li::before { content: "\2192"; }
  • Arrows come from CSS, not from the HTML.
  • Screen readers skip decorative content like this.

Attribute selectors

input[type="email"] { border: 2px solid green; }

Only the e-mail field is framed green:

a[href$=".pdf"] { color: #c0392b; }

The $= operator matches the end of a value, so the rule below would colour every download link red. Neither link in this sentence ends in .pdf, so both keep the normal styling — an internal page and a style sheet.

Selector reference

Selector Example Selects
Universal * Every element on the page
Type p Every element with that tag name
Class .card Every element with class="card"
Id #pricing The one element with id="pricing"
Descendant nav a Every link inside a nav, at any depth
Child ul > li List items that are direct children of a list
Grouping h1, h2, h3 All three, with one block of declarations
Pseudo-class a:hover A state of the element, not the element itself
Pseudo-element p::first-line A part of the element, created or picked by CSS
Attribute input[type="date"] Elements with that attribute (and value)
