One box per method

1. Inline

style attribute

Written on the element: style="color: red;". It only affects that one tag.

2. Embedded

<style> in <head>

One rule block styles every tag with this class on this page. Other pages cannot use it.

3. External

style4.css

One file, linked in <head>, styles every page that links it. The browser caches it once.

Which one should you use?

Method Written where Reaches Use it for
Inline style="..." on the tag That one tag A one-off change, or CSS sent inside an email
Embedded <style> in the head The whole page A page whose styling is never reused
External A separate .css file Every page that links it Almost everything — this site included

The cascade: who wins

When two rules set the same property on the same element:

  1. Inline beats embedded, and embedded beats external.
  2. A more specific selector wins: #id beats .class, which beats element.
  3. If the selectors are equally specific, the rule written last wins.
  4. !important overrides all of the above — and should almost never be used.

Anatomy of a rule

Every CSS rule is a selector, then a block of declarations:

h1 {
    color: #1f4e79;
    font-size: 2rem;
}
  • h1 is the selector — which tags the rule applies to.
  • color and font-size are the properties.
  • #1f4e79 and 2rem are the values,
  • and each pair ends with a semicolon, inside curly braces.
